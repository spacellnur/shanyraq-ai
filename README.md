# Шаңырақ AI

Колледждерге арналған ИИ-агенттер желісінің прототипі (Codex Challenge, колледж бағыты).

- Іске қосу: `python build.py`, содан кейін `dist/index.html` (немесе Windows-та `Запустить.bat`).
- Демо-аккаунттар: `admin`, `analyst`, `oblys`, `director`, `zam`, `kadr`, `buh`, `teacher`, `psix`, `soc` — құпиясөз `demo`.
- Барлық деректер синтетикалық. Агенттердің жұмысы мен дайын құжаттар — имитация (MVP).

Үшінші тарап материалдары: three.js (MIT), Kenney 3D-модельдері (CC0), geoBoundaries (CC BY 4.0), Golos Text (OFL).
