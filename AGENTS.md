# Шаңырақ AI — инструкция для Codex

Веб-прототип для колледжей Казахстана: вход по ролям, иерархия видимости (Министерство → область → колледж → отдел → сотрудник), 3D-сеть (карта РК, Түркістан облысы, районы, 7-этажное здание колледжа), 3D-кабинеты сотрудников, Networking (витрина и публикация ИИ-агентов), админка.

## Сборка и запуск
- Сборка: `python build.py` → `dist/index.html` (один файл, всё встроено: модели GLB base64, шрифт, данные карты).
- Локально на Windows: `Запустить.bat` → собирает и открывает http://localhost:8080 (сервер `tools/server.ps1`, автообновление через `dist/ver.txt`).
- Публикация: push в `main` → GitHub Actions (`.github/workflows/pages.yml`, образец в `tools/pages.yml`) собирает и выкладывает на GitHub Pages.
- Внешние зависимости только из CDN: three.js r128, OrbitControls, GLTFLoader, SkeletonUtils (jsdelivr/cdnjs). Не добавляй npm-сборщики без необходимости.

## Где что лежит
| Файл | Что внутри |
|---|---|
| `src/shell.html` | разметка, базовые стили 3D-вкладки, плейсхолдеры `<!--GLB-->`, `<!--MAIN-->`, `<!--APP-->`, `/*APPCSS*/` и др. |
| `src/main.js` | 3D-сцена колледжа: агенты, лифт, сценарии `run()`, `TASKS`, фоновая жизнь `ambient()`. Вставки `/*FLOORS*/` и `/*NET*/` |
| `src/floors.js` | этажи: `FLOORS`, `STAFF`, обстановка каждого этажа, анимации `ANIM` |
| `src/net.js` | карта: Казахстан, области, районы, колледжи, `setView`, кнопки Артқа/Алға, `window.APP3D` |
| `src/docs.js` | готовые документы и `PRESETS` (сценарии здания) |
| `src/app.js` | приложение: `ROLES`, `EVENTS`, `canSee`, вход, главная, «Кабинеттер» (`AGSET`, `STAFF`, `NEEDS`), Networking, админка |
| `src/app.css`, `src/fonts.css` | стили интерфейса, шрифт Golos Text (base64) |
| `templates/office.html` | шаблон 3D-кабинета; `build.py` переводит его на казахский и встраивает как `CAB_HTML` (iframe srcdoc) |
| `data/kz.json`, `data/obl.json`, `src/colleges.txt` | контур РК, области (geoBoundaries, до 2022), 50 колледжей Түркістан облысы |

## Правила
- Интерфейс на казахском. Тексты простые, без канцелярита.
- Стиль спокойный: Golos Text, тёмно-синий `#0E2A47`, тонкие рамки, без градиентов и теней на карточках, без надписей капсом.
- Данные только синтетические. Не добавлять реальные персональные данные студентов.
- Имитацию (заранее написанные документы, анимация агентов) явно подписывать в интерфейсе.
- Записи психолога — «Құпия»: не показывать их другим ролям.
- Видимость всегда через `canSee` / `canSeeCab`: нижний уровень не видит верхний, колледжи не видят друг друга.
- `localStorage` только через `store.get/set` (try/catch).
- После изменений: `python build.py`, открыть `dist/index.html` через localhost, пройти тест из PLAN.md.
